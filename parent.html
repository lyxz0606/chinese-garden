检查这台设备与离线使用

iPad / iPhone 怎样安装和断网使用
  1. 在 Safari 打开这个 HTTPS 网址。
  2. 点“分享 → 添加到主屏幕”，再从主屏幕图标打开。
  3. 在本页保存全部内容，保持页面在前台，等到显示“全部内容已保存”。
  4. 关掉 Wi-Fi 和蜂窝数据，从主屏幕重新打开，分别试一个识字活动、拼音活动和声音。

本地 Wi-Fi 的 HTTP 入口用于试用，手机不能通过它安装离线缓存。电脑 localhost 可用于技术检查。更新会先准备约189MB的完整新版，旧版继续可用。系统清理网站数据或卸载图标可能清除本机内容，请保留记录备份。

怎样判断正在进步

识字与阅读

每周 25—35 个字作为新增接触量。先认字、读词，再读句子和故事；需要帮助的字优先复习，能在不同日期独立认出的字逐渐拉开复习间隔。

拼音与应用

跟着学 → 自己试 → 换个场景用。推荐依据听辨、拼读和口头应用分别观察，点对选项不等于会读；听过提示的尝试单独记录。

59 项拼读练习提供卡片合拢、完整音节核对和可用的慢听。连续动作示范仍由家长带读；当前录音是完整音节，没有把分段拼接或慢放标为专门的教师连读录音。

男声和女声按发音清晰度选用。bīn、bīng 等受许可限制的原录音保持原速。无需一次学完所有内容，孩子愿意继续时再往前走。
