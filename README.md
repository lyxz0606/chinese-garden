# 语文小花园

适合家长陪伴的识字、阅读和拼音学习网页。包含 1200 个目标字、40 个单元、80 篇短阅读、20 组拼音路线和多种练习。

## 使用

通过 GitHub Pages 的 HTTPS 入口打开，在 Safari 中添加到主屏幕。从主屏幕进入后，到家长页保存全部课程与声音；完成后可断网使用。首次完整下载约 200 MB。学习记录保存在当前设备，可手动导出并在另一台设备导入。

## 内容和许可

本仓库仅包含运行网页所需的程序、课程、图形、字体、录音及来源说明。无账户系统，不收集家庭学习记录。课程和程序为本项目独立编写；第三方素材分别适用原许可，不能将整个仓库视为统一开放许可的音频素材库。来源说明见 [使用说明与素材来源](sources.html)、[拼音声音来源](pinyin/course-audio-sources.html) 和各素材目录内的许可记录。用途为家庭非商业学习。

59 项互动拼读练习提供完整音节核对及可用的慢听，轻短声母接韵母的连续动作仍由家长示范。
